---
title: "Environment Variables"
---

| variable | description |
| --- | --- |
| `STRAPI_HOSTNAME` | URL to the STRAPI instance |
| `LOCALE` | language to use in this instance of the job-alert microservice |
| `LUMO_WEBSITE` | LUMO website where the templates can be found |
| `SMTP_TLS` | true/false whether to use TLS or not |
| `SMTP_HOST` | SMTP server |
| `SMTP_PORT` | SMTP portnumber |
| `SMTP_USERNAME` | SMTP username |
| `SMTP_PASSWORD` | SMTP password |
| `SMTP_FROM_EMAIL` | Emailaddress used to sent the emails from |
| `BEARER_TOKEN_SECRET` | Bearer authentication token |
| `SEND_DAY_OF_WEEK` | On what day should the e-mail be sent |
| `SEND_HOUR` | At what time shout the e-mail be sent |
| `CRON_DISABLED` | Is the automatic process of sending job-alerts disabled |
| `SEND_SUBSCRIPTION_EMAILS` | Should subscription update mails be sent. (Requires additional templates in the webiste) |
